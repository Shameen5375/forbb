# for bb, always

A tiny static link hub for bb, designed for GitHub Pages.

## Customize

Update the three external URLs in `script.js`:

- `playlist`: the playlist
- `photos`: the photo album
- `letter`: the love letter

The `note` link points to the built-in cute note section and does not need a URL.

The text and visual styling live in `index.html` and `styles.css`.

## Deploy to GitHub Pages

1. Push the repository to GitHub.
2. Open **Settings > Pages**.
3. Choose **Deploy from a branch**, select `main`, and choose `/ (root)`.
4. Save. GitHub will publish the static files at the Pages URL for the repository.# forbb
